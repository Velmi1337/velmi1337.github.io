ALOL 1.0.1. Two games. One launcher.

Play Arizona RP and Rodina RP on Linux with a Material 3 Expressive launcher. Now available on AUR as alol, with AppImage and native packages for other setups.

Install from AURDownload 1.0.1Source code

For Linux x86_64. Game files and Windows components are not bundled. You need the official Arizona installer, an appropriate Wine/Proton environment and suitable graphics drivers.

AUR

ALOL is available on AUR.

alol

On Arch Linux and CachyOS, install the alol package. Enable multilib and install base-devel; your AUR helper resolves the build and runtime dependencies.

yay -S alol

Or use paru -S alol.

Update with: yay -Syu / paru -Syu.

Install from AUR

AppImage and native Arch/CachyOS and Fedora packages are also available on GitHub. Wine/Proton and graphics drivers are needed to play.

Getting started

Get a game environment ready.

  1. Install alol from AUR using yay or paru, or download an AppImage, Fedora 44+ RPM or Arch/CachyOS package.
  2. Follow the installation guide. Choose light or dark appearance in Settings → Launcher.
  3. Select the official Arizona Games installer in ALOL, then download the selected game through the official launcher.
  4. Close the official launcher, choose Arizona RP or Rodina RP and a server, then launch. Arizona uses a saved nickname; Rodina asks for it in-game.

A new interface. A simpler routine.

Arizona RP and Rodina RP

Switch games with separate server choices, settings, mod catalogs and repair targets. Arizona nicknames stay per-server; Rodina naming stays in-game.

Material 3 Expressive

Google Sans, light/dark themes, adaptive navigation and short settings categories. Switches save instantly; Ctrl+Enter launches the game.

Mods with rollback

Browse the catalog, manage installed mods or add an archive. Inspect files and dependencies before installation, then enable, disable or remove with file restoration.

Useful operation logs

Search records, filter errors, pause updates, follow new lines, copy the visible view and clear the current log and archive.

Wine, Proton and maintenance

Prepare fonts and components, keep Russian locale local to the game, repair common issues with backups, and check for ALOL updates.

Read the requirements first.

ALOL targets Linux x86_64. AUR builds require multilib and base-devel; AppImage requires glibc 2.35+ (Ubuntu 22.04+). Fedora packages target 44+. Playing requires Wine/Proton and suitable drivers. ALOL is independent of Arizona Games and does not include the game.

ALOL 1.0.1 code is Apache-2.0. Bundled Google Sans is OFL-1.1; the optional Wine patch is LGPL-2.1-or-later with corresponding source. Earlier tags retain their own licenses.
