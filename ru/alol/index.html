ALOL: Arizona RP на Linux.

Управляйте окружением Windows-игры из нативного Linux-лаунчера: выбирайте серверы, сохраняйте никнеймы, настраивайте моды и исправляйте типичные проблемы окружения.

Скачать на GitHub ↗Исходный код ↗

Для Linux x86_64. Игра и Windows-компоненты в пакет не входят. Нужны официальный установщик Arizona, подходящее окружение Wine/Proton и графические драйверы.

Подготовьте игровое окружение.

  1. Скачайте подходящий файл из последнего релиза GitHub: пакет Arch/CachyOS, Fedora RPM или описанный альтернативный вариант.
  2. Установите пакет по инструкции. Для Arch-подобных систем нужны multilib и подходящие 32/64-битные драйверы; требования Wine/winetricks для RPM описаны в документации.
  3. Скачайте установщик с официального сайта Arizona и выберите .exe в ALOL. Загрузите или обновите игру через официальный лаунчер.
  4. Закройте официальный лаунчер, выберите сервер и никнейм, затем запускайте игру через ALOL.

Опубликованные пакеты предназначены для Linux x86_64; есть инструкции для Arch/CachyOS и Fedora 44+. Совместимость зависит от рантайма и драйверов. ALOL независим от Arizona Games и не содержит игру.

Текущие исходники разработки используют Apache-2.0. Ранее опубликованные теги и архивы, включая 0.5.7, сохраняют указанную в них MIT-лицензию. Проверяйте лицензию распространяемой версии.

Скриншот сделан с демонстрационным профилем: он показывает интерфейс, а не подтверждение живой игровой сессии.
